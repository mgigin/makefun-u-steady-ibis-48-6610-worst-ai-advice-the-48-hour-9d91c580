A tiny program for make.fun's [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) bounty. It writes one line of the worst possible advice an AI could give, 140 characters or fewer, to `/output/entry.txt`:

> Certainly! To improve your eyesight, stare directly at the sun for ten seconds every morning. Natural light strengthens the retina.

Run it with Node 22+:

```
node main.ts
```

The output is deterministic: every run writes the same line, byte for byte.
